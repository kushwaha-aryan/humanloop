# Screenshots

Add the four images referenced in the main README before publishing:

- `overview.png` — Overview with today's tasks and the demo-mode banner
- `clarity.png` — a generated plan with estimates and "done when"
- `focus.png` — Focus Mode with a running timer
- `reflection.png` — a completed reflection with wins and next steps

Capture at 1440 × 1000 in the dark theme at 100% browser zoom. Use only real
states produced by the app; do not mock up UI or edit the screenshots beyond
cropping. To reproduce the demo state, start the app with `GROQ_API_KEY` empty
and follow the normal Clarity → Tasks → Focus → Reflection flow.

PNG is preferred. Keep each file under ~500 KB by exporting at the capture size
rather than downscaling the UI.
